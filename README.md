# Jeu du Nombre Mystère

Petit jeu de devinette en JavaScript.

## Fichiers

- `index.html` — page interactive : devine un nombre entre 1 et 50 avec indices "plus grand" / "plus petit" et historique des essais.
- `script.js` — fonction utilitaire autonome (`devinerNombre`) comparant une proposition à un nombre secret fixe.

## Utilisation

Ouvre `index.html` dans un navigateur pour jouer.
